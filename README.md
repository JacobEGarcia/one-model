# ONE MODEL

One policy. Two robot arms. One ball. Keep it airborne.

A browser game about multi-robot coordination, inspired by @Em_Nomadic and the MuJoCo juggling sims of GPT 6 Astra orchestrating two robots with one ball.

You are the model. Left arm: A/D move + W strike. Right arm: arrows + Up strike. Touch: drag each half of the screen, tap to strike.

Built with Godot 4.4 (web export) + Blender-modeled robot arms.

Play: https://jacobegarcia.github.io/one-model/
